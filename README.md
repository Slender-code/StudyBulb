# StudyBulb
A beginner-friendly Android application that helps students study, prep, and organize study material. 

# Project Overview
StudyBulb is an Android Application I am developing to help students study for exams without false marketing, subscriptions, and mismanagement. The goal is to make it easier for students to study, prepare, and organize study material before upcoming exams and quizzes. 

As a college student who is studying for exams and quizzes, there is financial stress around subscriptions, false marketing, and the lack of organization from other study platforms. Some features are locked behind a paywall preventing students from studying effectively and efficiently for exams.  

# Purpose of Application
I believe students should be able to access study tools and features without a price to ensure success in the classroom. This application will allow students to study and prep for exams without having to use multiple platforms or accounts. 

# Planned Features
- Flashcard creation
- Matching sets
- Reminders
- Planner
- Pomodoro timer
- Simple UI for users
